# Техническое задание: Сайт детского психолога maryglinskaya.com

## 1. Общая информация

**Цель**: Создать SEO-оптимизированный **многостраничный сайт** для детского и подросткового психолога Марии Глинской в Варшаве

**Целевая аудитория**: 
- Русскоязычные родители с детьми 3-17 лет
- Проживающие в Варшаве или по всей Европе (для онлайн-консультаций)

**Платформа**: Cloudflare Pages (статический сайт)

- Каждая услуга = отдельный HTML-файл

- Адаптивный дизайн (mobile-first)
- Быстрая загрузка (PageSpeed Score > 90)

## 2. Архитектура: Почему многостраничный сайт критичен для SEO

### ⚠️ ВАЖНО: Это НЕ одностраничник (SPA/лендинг)!

#### ❌ ПЛОХО: Одностраничник (что НЕ нужно делать)

```
maryglinskaya.com/                    (одна страница)
├── #главная                          (якорь)
├── #о-себе                           (якорь)
├── #услуги                           (якорь)
└── #контакты                         (якорь)

Результат:
→ Google видит только 1 страницу
→ Можно оптимизировать под 1-2 запроса максимум
→ Конкурент легко обгоняет
→ Нет возможности расширяться
```

#### ✅ ХОРОШО: Многостраничный сайт (что нужно)

```
maryglinskaya.com/                              (отдельный HTML-файл)
maryglinskaya.com/o-sebe                        (отдельный HTML-файл)
maryglinskaya.com/uslugi/detskaya-terapiya      (отдельный HTML-файл)
maryglinskaya.com/uslugi/podrostkovaya-terapiya (отдельный HTML-файл)
maryglinskaya.com/kontakty                      (отдельный HTML-файл)

Результат:
→ Google видит 10+ отдельных страниц
→ Каждая страница оптимизирована под свой запрос
→ Множество входных точек из поиска
→ Легко добавлять новые услуги и статьи
```

**Проблема одностраничников для психолога:**
- Можно оптимизировать только под 1-2 запроса максимум
- Google не видит отдельные разделы услуг
- Конкуренту (@mashabel_psy) легче обогнать вас по всем запросам
- Невозможно расширить на новые услуги без потери SEO

**Решение: Многостраничная архитектура**

Каждая услуга = отдельная страница = отдельный запрос в Google:

```
Страница                                          Главный запрос в Google
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
/                                                 "детский психолог варшава"
/uslugi/detskaya-terapiya                         "детский психолог варшава"
/uslugi/podrostkovaya-terapiya                    "подростковый психолог варшава"
/uslugi/onlajn-terapiya                           "психолог онлайн русскоязычный"
/uslugi/konsultacii-roditelej                     "консультации для родителей варшава"
/blog/kak-pomoch-rebenku-s-trevozhnostyu          "как помочь ребенку с тревогой"
```

**Каждая страница:**
- ✅ Уникальный URL для индексации
- ✅ Свой Title, Description, H1 под конкретный запрос
- ✅ Отдельная входная точка из Google
- ✅ Возможность расширяться (блог, новые услуги)

**Техническая реализация:**
- Отдельные HTML-файлы для каждой страницы
- Общий CSS/JS (переиспользуется)
- Header/Footer одинаковые (можно создать компоненты)
- Обычные ссылки `<a href="/o-sebe">` (НЕ JavaScript-роутинг!)

## 3. Дизайн и UX

### 3.1 Общий стиль

**Характер дизайна:**
- Профессиональный, но тёплый и доверительный
- Спокойные, успокаивающие цвета
- Минималистичный, без перегрузки элементами
- Дизайн должен вызывать доверие и ощущение безопасности

**Цветовая палитра:**
```
Основной цвет: #4A90A4 (спокойный голубой)
Акцентный: #F4A460 (тёплый персиковый)
Текст: #333333 (тёмно-серый)
Фон: #FFFFFF (белый) + #F9F9F9 (светло-серый для секций)
```

**Типографика:**
- Заголовки: Montserrat (Google Fonts), жирность 600-700
- Основной текст: Open Sans или Inter (Google Fonts), жирность 400
- Размер: минимум 16px для основного текста (читаемость)

**Визуальные элементы:**
- Мягкие скругления углов (border-radius: 8-12px)
- Subtle shadows для карточек
- Иконки: использовать Font Awesome или Lucide Icons (простые, понятные)
- Изображения: профессиональные фото, иллюстрации детей/семей (можно stock-фото с Unsplash)

## 4. SEO-требования

### 4.1 On-Page SEO

**Каждая страница должна иметь:**
1. ✅ Уникальный `<title>` (50-60 символов)
2. ✅ Уникальный `<meta name="description">` (150-160 символов)
3. ✅ H1 заголовок (один на страницу, с ключевым словом)
4. ✅ Структура заголовков H2-H3 (логичная иерархия)
5. ✅ Alt-тексты для всех изображений с ключевыми словами
6. ✅ Schema.org разметка (см. ниже)

**Ключевые слова для использования:**
- Главная: "детский психолог варшава", "подростковый психолог", "психолог для детей"
- Детская терапия: "детский психолог варшава", "психолог для детей"
- Подростковая: "подростковый психолог варшава"
- Онлайн: "психолог онлайн", "русскоязычный психолог европа"

**Плотность ключевых слов:** 
- Естественное вхождение 2-3 раза на страницу
- Не спамить, текст должен читаться легко

**Каждая страница = отдельный HTML файл с:**
- Полной HTML структурой (<!DOCTYPE html>, <head>, <body>)
- Своими уникальными мета-тегами
- Ссылкой на общий CSS/JS
- Header и Footer (можно копировать или использовать includes)

**Стек технологий:**

**Вариант 1 (простой):** Чистый HTML5/CSS3/JavaScript
- Создай отдельные HTML-файлы вручную
- Плюсы: просто, быстро, полный контроль
- Минусы: приходится дублировать Header/Footer

**Вариант 2 (рекомендуется):** Astro или 11ty
- Генератор статических сайтов
- Компоненты для Header/Footer
- На выходе = чистые HTML-файлы
- Плюсы: нет дублирования кода, удобно поддерживать
- Минусы: нужно настроить сборку

**Вариант 3:** Next.js с Static Export
- `next export` создаст HTML для каждой страницы
- Плюсы: мощный инструмент, удобная разработка
- Минусы: оверкилл для такого сайта

**CSS подход:**
- Mobile-first
- Использовать CSS Grid и Flexbox
- CSS переменные для цветов
- БЭМ-методология для именования классов (опционально)
- Один файл `style.css` подключается ко всем страницам

**JS функции:**
- Валидация формы
- Плавная прокрутка
- Lazy loading изображений
- Мобильное меню (toggle)
- Один файл `main.js` подключается ко всем страницам

**Важно:**
- Код должен быть чистым и комментированным
- Семантичная HTML-разметка
- Доступность (ARIA-labels где нужно)
- Кроссбраузерность (Safari, Chrome, Firefox)
- НЕ использовать клиентский роутинг (React Router и т.п.)
- Каждая ссылка = обычный `<a href="/uslugi/detskaya-terapiya">` → загружает новую страницу
