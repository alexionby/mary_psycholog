# Мария Глинская - Детский и Подростковый Психолог

Профессиональный сайт для детского и подросткового психолога Марии Глинской в Варшаве.

## 🌟 Особенности

- **SEO-оптимизация**: Полная оптимизация для поисковых систем с мета-тегами, Schema.org разметкой и Open Graph
- **Адаптивный дизайн**: Mobile-first подход, отлично работает на всех устройствах
- **Высокая производительность**: Оптимизирован для быстрой загрузки (PageSpeed Score > 90)
- **Современный стек**: HTML5, CSS3, Vanilla JavaScript - никаких тяжелых фреймворков
- **Доступность**: Соответствует стандартам доступности (WCAG)
- **PWA поддержка**: Готовность к Progressive Web App

## 🚀 Развертывание на Cloudflare Pages

### Способ 1: Через GitHub (Рекомендуется)

1. **Подключите репозиторий к Cloudflare Pages**:
   - Войдите в [Cloudflare Dashboard](https://dash.cloudflare.com/)
   - Перейдите в раздел "Pages"
   - Нажмите "Create a project"
   - Выберите "Connect to Git"
   - Авторизуйте GitHub и выберите этот репозиторий

2. **Настройте параметры сборки**:
   - **Project name**: `mary-psycholog` (или любое другое имя)
   - **Production branch**: `main`
   - **Build command**: (оставьте пустым - статический сайт)
   - **Build output directory**: `/` (корень проекта)

3. **Разверните**:
   - Нажмите "Save and Deploy"
   - Ваш сайт будет доступен по адресу `https://mary-psycholog.pages.dev`

### Способ 2: Через Wrangler CLI

```bash
# Установите Wrangler
npm install -g wrangler

# Войдите в Cloudflare
wrangler login

# Разверните проект
wrangler pages publish . --project-name=mary-psycholog
```

### Способ 3: Через Direct Upload

1. Зайдите в Cloudflare Dashboard → Pages
2. Нажмите "Create a project" → "Upload assets"
3. Загрузите все файлы из корня проекта
4. Задайте имя проекта и нажмите "Deploy"

## 📧 Интеграция формы обратной связи

Для работы формы контактов необходимо настроить бэкенд. Варианты:

### 1. Cloudflare Workers (Рекомендуется)
Используйте Cloudflare Workers для обработки форм:
- Создайте Worker для приема POST запросов
- Настройте отправку email через SendGrid, Mailgun или Resend

### 2. Formspree
Самый простой вариант:
```html
<form action="https://formspree.io/f/YOUR_FORM_ID" method="POST">
```

### 3. EmailJS
Отправка email прямо из браузера:
```javascript
emailjs.send("service_id", "template_id", formData);
```
