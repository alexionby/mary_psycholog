# SEO-оптимизация maryglinskaya.com

## Что сделано

### Build-система (Фаза 0)
- Создан `build.js` — компилирует HTML из `src/` + `components/` в `dist/`
- Header/footer/services-grid инлайнятся при сборке (не загружаются через JS fetch)
- CSS объединяется и минифицируется: `style.css` + `responsive.css` → `style.min.css`
- JS минифицируется: `main.js` → `main.min.js` с `defer`
- Critical CSS инлайнится в `<style>` в `<head>` каждой страницы
- Cloudflare Pages: build command `node build.js`, output `dist/`

### Meta-теги, Canonical, Open Graph (Фаза 1)
- Уникальные `<title>` и `<meta description>` на всех 13 страницах
- `<link rel="canonical">` на каждой странице
- Open Graph теги (og:type, og:title, og:description, og:image, og:locale)
- Twitter Card (`summary_large_image`)
- Удалены устаревшие `<meta name="keywords">`
- Все CSS/JS пути приведены к абсолютным (`/css/...`, `/js/...`)

### Schema.org JSON-LD (Фаза 2)
- `ProfessionalService` — на всех страницах (имя, адрес, цены, соцсети)
- `Article` — на 2 блог-постах (автор, даты публикации)
- `Service` — на 6 страницах услуг (название, описание, провайдер)
- `BreadcrumbList` — на всех страницах кроме главной

### Ссылки и навигация (Фаза 3)
- Исправлены битые `href="#"` в services-grid на реальные URL
- Добавлен "Блог" в навигацию (desktop + mobile)
- Раскомментирована карточка "Онлайн-терапия"
- Исправлен `<h2>` → `<h1>` на странице "О себе"

### Оптимизация изображений (Фаза 4)
- Hero-фото: WebP (73KB) + JPG fallback через `<picture>`
- Иконки (b17, instagram, telegram, whatsapp): уменьшены с МБ до КБ (48x48px)
- `width`/`height` на всех `<img>` для предотвращения CLS
- `fetchpriority="high"` на hero-изображении

### Производительность (PageSpeed 100/100)
- Шрифты Google Fonts захостены локально (`fonts/*.woff2`)
- `@font-face` декларации в critical CSS (инлайн) — шрифты грузятся сразу
- `<link rel="preload">` для кириллических woff2 (Inter + Playfair Display)
- CSS загружается синхронно (async-паттерн убран — причина CLS)
- Контраст footer-текста исправлен для WCAG AA (#555 вместо #6b6b6b)

**Результат PageSpeed (mobile): 100 / 95→100 / 100 / 100**
**Результат PageSpeed (desktop): 100 / 100 / 100 / 100**

### Footer (Фаза 5)
- Расширенный footer: навигация, контакты, соцсети, копирайт
- CTA-секции в блог-постах ("Записаться на консультацию")

### Sitemap и техническое (Фаза 6)
- `sitemap.xml` обновлён (13 URL, lastmod, changefreq)
- `robots.txt` настроен
- Google Search Console: сайт добавлен, sitemap отправлен (13 страниц обнаружено)
